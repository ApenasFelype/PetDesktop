# 🐱 PetDesktop

Um pequeno **pet virtual para desktop** desenvolvido em **C# e WPF**.

O projeto consiste em um gato que fica sobre a área de trabalho do Windows, podendo andar pela tela, ficar parado e ser arrastado pelo usuário.

## ✨ Funcionalidades

Atualmente, o PetDesktop possui:

*  Pet virtual em formato de gato
*  Movimento horizontal pela tela
*  Estado parado/idle
*  Gravidade
*  Possibilidade de pegar e arrastar o gato
*  Pet funcionando diretamente sobre o desktop

## 🛠️ Tecnologias

* **C#**
* **WPF (Windows Presentation Foundation)**
* **.NET**
* **Visual Studio**

## 🎮 Como funciona

O gato é executado como uma janela do WPF posicionada sobre a área de trabalho.

Seu comportamento é controlado através de diferentes estados, como:

* **Idle:** o gato fica parado.
* **Walking:** o gato se movimenta horizontalmente.
* **Gravity:** o gato cai quando não está apoiado em uma superfície.
* **Dragging:** o usuário pode clicar e arrastar o gato pela tela.
